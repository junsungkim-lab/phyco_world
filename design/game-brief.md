# Game Brief: phyco world (싸이코 월드)

**One-sentence pitch:** 정성껏 꾸민 내 미니홈피 방에 친구가 놀러 와서, 방명록만 남기는 게 아니라 방을 어지럽히고 불 지르고 똥 싸고 도망가는 장난 미니홈피.

## Core loop
- 주인: 방을 가구로 꾸미고 BGM을 고른다 → 친구를 초대한다
- 방문자: 방에 들어와 장난(어지럽히기 / 불지피기 / 똥싸고 도망가기)을 치고 방명록에 흔적을 남긴다
- 주인: 돌아와서 난장판을 확인하고 웃은 뒤 청소한다 → 다시 꾸미고 복수하러 친구 집에 간다

## Player goal & fail state — what "working" looks like
- 방문자가 장난 하나를 치면 3초 안에 방이 눈에 띄게 망가지고, 그 기록이 방명록에 자동으로 남는다.
- 주인이 "청소" 한 번으로 원래 꾸민 상태로 돌아갈 수 있다. (실패 상태 없음. "웃기면 성공")

## MVP — what must exist to be the game
- 방문자 수 (TODAY / TOTAL)
- 방명록 (이름 + 글 + 시간, 장난 자동 기록)
- BGM 설정 (곡 선택, 재생/정지)
- 미니룸 꾸미기 (가구 놓기, 옮기기, 빼기)
- 장난 3종: 어지럽히기, 불지피기, 똥싸고 도망가기
- 청소하기 (원상복구)

## Out of scope — not building this
- 로그인, 실제 다중 사용자 서버 (프로토타입은 브라우저 localStorage에만 저장)
- 일촌, 다이어리, 사진첩, 도토리 같은 결제
- 모바일 앱 패키징

## Build order
1. 미니룸 + 장난 3종 (재미 검증이 제일 위험하니 먼저)
2. 청소 / 꾸미기
3. 방명록 자동 기록, 방문자 수
4. BGM

---
**Who it's for / what they feel:** 친한 친구끼리, "야 내 방 왜 이래 ㅋㅋㅋ" 하는 웃음.

**Art & audio direction:** 2000년대 감성의 도트 미니룸, 이펙트는 pixelfx(MIT) 사용, 8비트 칩튠 BGM.

**Reference game:** 2000년대 한국 미니홈피 서비스의 "방문자 수 + 방명록 + BGM + 미니룸" 구성만 참고. 이름, 로고, 그림은 쓰지 않고 오리지널로 만든다.
